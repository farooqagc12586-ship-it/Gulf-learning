3. Lesson 1 — Computer & Programming Basics

3.1 What is programming?

Programming means giving a computer a list of instructions, in order, to do a job.

Real-life example — a recipe:

1. Boil water
2. Add pasta
3. Wait 10 minutes
4. Drain water

That is a program. The cook is the computer. If step 2 comes before step 1, the result is wrong. Computers are the same — order matters.

Memory Trick Programming = writing a recipe for a very obedient but very literal assistant.

3.2 What is code?

Code is the written form of those instructions. It is text, saved in a file, that a computer can read and follow.

Code is not magic. It is just instructions written in a language the computer understands.

3.3 What is a programming language?

Computers only understand 0 and 1. Writing in binary is painful for humans. So we invented programming languages — halfway between human language and machine language.

Examples: HTML, CSS, JavaScript, Python. Each has its own syntax (rules of grammar).

Memory Trick Syntax = grammar. let x = 5; is correct grammar in JavaScript. let 5 x =; is not.

3.4 What is a website?

A website is a set of files stored somewhere that a browser can download and display.

  • Static — the same for everyone (a business card page).
  • Dynamic — changes based on who you are or what you do (your email inbox).

3.5 What is a web application?

A web application is a website you can interact with — type into, click, submit, get results.

  • A page showing your school's address → website.
  • A page where you log in and take an exam → web application.

Our final project is a web application.

3.6 What is a browser?

A browser (Chrome, Firefox) is the program that:

  1. Asks a server for files.
  2. Reads HTML, CSS, JavaScript.
  3. Draws the result on your screen.

The browser is the customer in a restaurant — it asks, receives, and enjoys the meal.

3.7 What is a server?

A server is a computer that is always on and always waiting to send files or data when asked.

Your laptop can be a server. Real servers live in data centres and run 24/7.

Memory Trick Browser = customer. Server = waiter + kitchen.

3.8 What is frontend?

Frontend = everything the user sees and touches in the browser. Built with HTML, CSS, and JavaScript.

Memory Trick Frontend = the shop window and the counter.

3.9 What is backend?

Backend = the code running on the server. The user never sees it. It handles logging in, checking passwords, saving scores, sending emails. Built with Python, Flask, and similar tools.

Memory Trick Backend = the worker behind the counter.

3.10 What is a database?

A database is an organised place to store information permanently, so it survives even after the computer restarts.

Filing cabinetDatabase
CabinetDatabase
DrawerTable
One folderRow (one record)
"Name" field on a formColumn

3.11 What is a URL?

URL = Uniform Resource Locator = the address of a page.

https://www.school.com/exam/result
│      │              │
│      │              └── path (which page)
│      └── domain name (which website)
└── protocol (how to talk)
Memory Trick URL = the house address of a webpage.

3.12 What is hosting?

Hosting means renting space on an always-on server so other people can visit your website.

  • Your website lives on your computer → only you can see it.
  • Your website lives on a hosting server → the whole world can see it.

3.13 How it all fits together

When you type www.school.com and press Enter:

1. Browser asks DNS: "Where is school.com?" → gets an IP address
2. Browser asks that server: "Please give me the page"
3. Server (backend) may ask the database for data
4. Server sends back HTML + CSS + JS
5. Browser draws the page (frontend)
6. You click, type, submit → repeat

That loop is the whole web. Everything we learn is a piece of it.
